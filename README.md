# Patas Amigas - Landing Page 🐾

Este é o projeto de uma landing page para uma ONG fictícia de proteção e adoção de animais, chamada "Patas Amigas". O projeto foi desenvolvido como um desafio acadêmico de Front-end, seguindo rigorosamente restrições técnicas para validar os fundamentos de HTML5 e CSS3.

🔗 **[Acesse o site aqui (Link Placeholder)](https://seu-usuario.github.io/patas-amigas)**

## 🛠 Tecnologias Utilizadas

- **HTML5:** Código estritamente semântico (usando tags como `<header>`, `<main>`, `<article>`, `<address>`), focado em acessibilidade (`alt` descritivo nas imagens e navegação fluída).
- **CSS3:** Organizado através de Variáveis CSS (Custom Properties), Flexbox e CSS Grid.
- **Mobile-First:** A responsividade foi garantida por meio de Media Queries, desenhando primeiramente para o celular e adaptando para tablets e desktops, sem quebras ou barras de rolagem horizontal.
- **Sem JavaScript:** Toda a estrutura, reorganização do menu em telas menores, botões, e efeitos visuais (`:hover`, `:focus`) foram criados exclusivamente com CSS e HTML, cumprindo com o escopo do desafio.

## 🤖 Uso de Inteligência Artificial

A Inteligência Artificial (IA) foi utilizada neste projeto com o propósito de mentoria e auxílio na estruturação de código seguindo as melhores práticas do mercado, atuando como um "professor sênior". 

Abaixo está o registro de como a ferramenta colaborou com o processo de desenvolvimento:

1. **Prompt:** *"Atue como um desenvolvedor front-end sênior e professor. Preciso implementar a landing page de um desafio acadêmico..."*
   - **Como a IA ajudou:** Gerou o esqueleto inicial do HTML focado em semântica (evitando o uso excessivo e genérico de `<div>`), além de montar um CSS seguindo as boas práticas do mercado com variáveis, reset universal e estrutura "Mobile-First".
2. **Prompt:** *"Como organizar o layout do menu sem usar JavaScript para responsividade?"*
   - **Como a IA ajudou:** Recomendou a abordagem do `display: flex;` com `flex-wrap: wrap;`, o que permite que os botões se empilhem graciosamente quando há pouco espaço em telas de celular, mantendo a simplicidade e contornando a necessidade do uso do JavaScript para menus *hamburguer*.
3. **Prompt:** *"Qual a melhor tag para eu colocar os dados de contato?"*
   - **Como a IA ajudou:** Explicou que a tag `<address>` é semanticamente a mais correta para definir informações de contato do proprietário ou autor da página.
